# Tiger Music Tag Editor

Windows 桌面端的批量音频元数据（标签）编辑器。把一批本地音频文件导入为「工作区」，集中查看与修改标签，从在线库匹配元数据候选，确认后写回文件标签，并按模板重命名与归档。

> **当前状态**：已完成工程骨架（`backend/` + `desktop/`）、S0 技术验证（标签库读写、内存快照方案、在线源约束）与 **S0.5 前端 UI 基线**（One Dark / One Light 双主题原型 + Vue 3 组件落地，`typecheck` / `build` 通过）。前端界面基于内存模拟数据，**后端服务与真实数据对接尚未开始**。项目文档在本地 `docs/` 目录维护，不随本仓库发布。

## 功能特性

- **文件导入与工作区**：导入文件或文件夹，读取并展示现有标签；建立「首次元数据快照」作为提交前回滚目标。
- **标签查看**：以表格呈现每首曲目的字段值，多碟专辑按碟号分组显示。
- **手动排序与音轨号自动分配**：拖动调整顺序；按选定范围从 1 连续编号，并可按碟号分组分别编号。
- **批量 / 单独编辑**：单元格直接编辑，或对多首曲目批量设置同一字段。
- **在线元数据匹配**：接入 MusicBrainz + AcoustID，支持按单曲（指纹）与按专辑两种粒度；候选以表格列出供比较后应用。
- **封面与歌词**：单张封面（获取/替换/嵌入）与歌词编辑嵌入。
- **重命名与归档**：写前预览，自动处理非法字符、重名冲突与路径长度（首版提供内置固定模板）。
- **提交前回滚与确认写回**：写回前预览全部变更，确认后写入标签并重命名归档；提交前的编辑可恢复为首次读取值。
- **外部播放器试听**：不内置播放器，调用用户设置的外部播放器（如 foobar2000）打开当前曲目。
- **界面**：单窗口工作区（工具栏 + 曲目表格 + 详情/媒体区 + 状态栏），支持 One Dark / One Light 双主题；9 个交互模态（导入跳过项、按范围编号、批量编辑、在线匹配、歌词搜索、歌词编辑、重命名预览、写回确认、首选项设置）。

## 支持的音频格式与标签体系

| 格式 | 标签体系 |
|---|---|
| FLAC | Vorbis Comment |
| ALAC | iTunes 风格 |
| M4A | iTunes 风格 |
| AAC | iTunes 风格 |
| MP3 | ID3 |
| OGG | Vorbis Comment |
| WAV | RIFF / ID3 |

## 技术栈

- **后端**：Java 21 LTS + Spring Boot 3.5.x + Maven
- **前端**：Vue 3 + TypeScript + Vite
- **桌面壳**：Electron
- **通信**：本机 HTTP/JSON
- **存储**：首版不引入 SQL 数据库，工作区快照、编辑态与会话结果保存在 Java 服务内存中（会话级，不跨会话持久化）

> 已完成 S0 验证：jaudiotagger 3.0.1 对 FLAC / ALAC / M4A / AAC / MP3 / OGG / WAV 的标签读写通过；在线源约束见本地文档。

## 项目结构

```
backend/    Spring Boot 3.5.x + Java 21 后端（领域端口 + jaudiotagger 适配器；工作区与写回功能待实现）
desktop/    Electron + Vue 3 + TypeScript + Vite 桌面端
  prototype/      UI 静态原型（单文件 HTML，含双主题与全部交互）
  src/main/       Electron 主进程
  src/preload/    受限 preload 桥接
  src/renderer/   Vue 3 渲染层（组件、状态机、双主题 Token）
```
